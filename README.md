# 📝 MyZapis — Умный Telegram-бот для заметок, задач и голосовых с ИИ

Персональный ассистент для мгновенной фиксации мыслей, структурирования длинных голосовых сообщений, планирования задач и отправки своевременных напоминаний в часовом поясе **Екатеринбурга (UTC+5 / YEKT)**.

Работает на базе **бесплатных моделей OpenRouter** с интеллектуальным failover (автоматической ротацией моделей при перегрузке) и поддерживает **мгновенную транскрибацию речи (Groq Whisper-large-v3 / faster-whisper)**.

---

## 🌟 Ключевые возможности

1. **🎙 Транскрибация голосовых и кружочков**:
   - Принимает голосовые сообщения, аудиофайлы и видеосообщения (кружочки).
   - Транскрибирует через бесплатный **Groq Whisper-large-v3** (расшифровка за ~0.5 сек) или автономный локальный движок **faster-whisper**.
2. **🧠 Умное ИИ-структурирование через OpenRouter**:
   - Автоматически находит и использует бесплатные модели OpenRouter (`meta-llama/llama-3.3-70b-instruct:free`, `google/gemini-2.0-flash-thinking-exp:free`, `mistralai/mistral-small-3.2-24b-instruct:free`, `qwen/qwen-2.5-72b-instruct:free`, `deepseek/deepseek-r1:free` и др.).
   - Автоматический failover: при лимитах (HTTP 429) мгновенно переключается на другую бесплатную модель.
   - Выделяет:
     - **Краткую суть и ключевые тезисы**.
     - **Хронологию / таймлайн** для длинных аудио (ход мыслей, последовательность тем на встрече).
     - **Конкретные задачи (Action Items)** с распознаванием дат и дедлайнов.
     - **Тематические теги** для быстрого поиска.
3. **⏰ Умные напоминания (UTC+5, Екатеринбургское время)**:
   - Распознает формулировки вроде: *«напомни завтра в 14:00»*, *«в четверг утром»*, *«через 2 часа»*, *«25 сентября в 19:30»*.
   - Автоматически ставит напоминание в планировщик `APScheduler` за 15 минут до срока (настраивается).
   - При наступлении срока присылает сообщение с интерактивными кнопками:
     - `[✅ Выполнено]`
     - `[⏳ +15 мин]`
     - `[⏳ +1 час]`
     - `[📅 На завтра 10:00]`
4. **🔍 Интеллектуальный поиск (RAG / AI-поиск)**:
   - Команда `/ask <вопрос>`: найдет нужные заметки и ответит на естественном языке (например: *«/ask сколько мы договорились заплатить подрядчику?»*).
   - Команда `/search <слово>`: быстрый полнотекстовый поиск по заметкам.
5. **☀️ Утренний брифинг и вечерний отчет**:
   - В 09:00 YEKT присылает список планов на день.
   - В 21:00 YEKT подводит итоги дня и помогает перенести незавершенные дела.
6. **🔒 Безопасность и серверная изоляция**:
   - Доступ только для разрешенных пользователей (`ALLOWED_TELEGRAM_IDS`).
   - Развертывание в Docker без открытых портов (Telegram Polling): **не создает никаких конфликтов** с другими ботами или сайтами на сервере!

## 🚀 Быстрое развертывание на сервере (Ubuntu 24.04)

Сервер: 3 vCPU, 6 GB RAM, Ubuntu 24.04 (Амстердам).

### 1. Клонирование репозитория на сервер

```bash
git clone <URL_РЕПОЗИТОРИЯ> myzapis
cd myzapis
```

### 2. Настройка переменных окружения (.env)

Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
nano .env
```

Заполните обязательные поля:
- `BOT_TOKEN`: токен вашего бота от [@BotFather](https://t.me/BotFather).
- `ALLOWED_TELEGRAM_IDS`: ваш Telegram ID (узнать можно у [@userinfobot](https://t.me/userinfobot)), например `123456789`.
- `OPENROUTER_API_KEY`: бесплатный ключ с [openrouter.ai/keys](https://openrouter.ai/keys).
- `GROQ_API_KEY`: (рекомендуется) бесплатный ключ с [console.groq.com/keys](https://console.groq.com/keys) для мгновенной транскрибации через Whisper-large-v3.

### 3. Запуск одной командой

Сделайте скрипт исполняемым и запустите:
```bash
chmod +x deploy.sh
bash deploy.sh
```

Скрипт автоматически установит Docker (если его еще нет), соберет изолированный контейнер и запустит бота в фоновом режиме.

## 🛠 Управление ботом на сервере

- **Просмотр логов в реальном времени**:
  ```bash
  docker compose logs -f
  ```
- **Перезапуск бота**:
  ```bash
  docker compose restart
  ```
- **Остановка бота**:
  ```bash
  docker compose down
  ```
- **Обновление бота после изменений**:
  ```bash
  git pull
  bash deploy.sh
  ```

## 💻 Локальный запуск (без Docker, для разработки)

1. Установите зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Linux/macOS
   # или venv\Scripts\activate  # Windows
   pip install -r requirements.txt
   ```
2. Убедитесь, что установлен `ffmpeg`:
   - Ubuntu: `sudo apt install ffmpeg`
   - Windows: скачайте с официального сайта или через `winget install Gyan.FFmpeg`
3. Скопируйте и настройте `.env`:
   ```bash
   cp .env.example .env
   ```
4. Запустите:
   ```bash
   python -m app.main
   ```

## 📱 Список команд в Telegram

| Команда | Описание |
|---|---|
| `/start` | Приветствие и краткая инструкция |
| `/tasks` | Список всех активных задач с кнопками управления |
| `/today` | Задачи, запланированные на сегодня |
| `/notes` | Просмотр последних сохраненных заметок |
| `/search <текст>` | Поиск по заметкам и тегам |
| `/ask <вопрос>` | Умный вопрос ИИ по вашей базе заметок (RAG) |
| `/status` | Информация о статусе, серверном времени (YEKT) и активных моделях |
| `/help` | Подробная справка по работе с ботом |
